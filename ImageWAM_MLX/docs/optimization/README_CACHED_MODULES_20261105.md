# 当前10步文本缓存命中版本：模块耗时

2026-11-05实测，M5 Pro 15CPU/16GPU、24GiB统一内存，macOS27.2、MLX0.32.4。版本为当前正式 speed，text_cache_size=1，10步，H16，标准同一帧三图、39-token文本、固定噪声。

## 按截图形式展示

同一帧，单独记录首次1次（填充文本缓存），之后10次预热、50次无插桩正式计时；再单独50次逐模块同步剖析。单位ms。

|配置|视觉VAE编码|多模态前缀（含图像/文本/状态投影）|动作专家10轮|正常端到端|
|---|---:|---:|---:|---:|
|当前speed，文本缓存命中|28.16|77.40|62.52|169.40|

这是ImageWAM的模块划分，不与截图中的其他模型强行一一对应：视觉列不包含 img_in 投影；投影位于多模态前缀。多模态前缀不等于纯语言编码器，包含当前图像和状态参与的联合注意力与KV生成，不能因指令不变而整段复用。正常端到端来自独立的50次无模块同步请求。

## 完整模块分解

|模块|平均 ms|P95 ms|
|---|---:|---:|
|文本分词|0.185|0.194|
|文本特征缓存读取（text_encoder命中）|0.028|0.032|
|图像和状态预处理|2.471|2.612|
|VAE图像编码|28.164|28.301|
|多模态前缀/投影/KV生成|77.396|77.651|
|动作去噪10步|62.518|62.632|
|CPU结果转换/反归一化|0.172|0.186|
|模块均值相加|170.934|不相加|
|带模块同步的请求整体|171.079|171.494|
|**无插桩正常端到端**|**169.401**|**169.813**|

正常端到端中位数169.406 ms，范围168.616–170.428 ms。本轮结果与此前169.379 ms接近，差0.022 ms，属于复测波动，不是代码提速。

每模块前后同步改变异步重叠和调度，故模块总和不能充当正常端到端。缓存命中0.028 ms不代表重算Qwen只需0.028 ms。前缀和动作合计139.914 ms，约占同步模块总和81.85%；进一步优化应优先关注这两部分，而不是已经省掉的文本编码。

## 输出与启动成本

50次正常请求和50次剖析请求的action/normalized均逐值一致，并与此前169.379 ms测试保存输出一致。缓存统计1 miss / 111 hits，包括首次、预热、正式、剖析及额外trace请求。

本进程加载15.101 s，首次完整请求12.228 s，独立保留，不混入169.401 ms稳态。首次包含文本cache miss和首次编译等，系统/驱动缓存状态未控制；没有证据把较大启动波动归因到具体原因，也不能把它表述为固定冷启动耗时。
