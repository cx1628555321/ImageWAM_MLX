# Split-K 四元素向量归约实验（2026-11-04）

基线为当前最快已验证的 adaptive Split-K 路径。尝试把FP32部分和归约改为float4读取与二维线程布局，分别测试128、64线程组。各元素仍按原分块顺序累加；bias、gate与残差加法之间保留BF16舍入。量化矩阵乘、W1权重、三图处理和动态文本支持均不变，没有增加权重反量化。

M5 Pro，15CPU/16GPU，24GiB统一内存；macOS27.2，Python3.12.13，MLX0.32.4。

## 处理结论

没有证明稳定提速的候选，保留已有adaptive Split-K，不修改生产代码和上一版入口。

float4减少线程数和显式索引，但也增加每线程处理量，减少并行线程数；无法仅凭更少指令预测整体性能。没有GPU时间线，尚不能将微小退化归因到寄存器、调度或带宽的某一项。本轮已保留负结果，后续应优先重新定位主要模块瓶颈，避免继续围绕低占比归约盲目微调。
