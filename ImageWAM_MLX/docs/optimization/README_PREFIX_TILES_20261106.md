# native-w1 基础上的前缀分块验证

日期：2026-11-06。设备与启动方式见 [推理版本索引](../../README_INFERENCE_VERSIONS.md)。

## 基准与约束

优化基础是新 MLX 运行时的 `native-w1`，此前 ABBA 端到端均值 146.903 ms。
三张 RoboTwin 图像逐次编码、文本特征缓存命中、10 步去噪；不减少步数、不缓存图像，不改变权重和计算精度。
每个完整测试进程预热10次、正式测量50次，模块计时另外测量50次。模块计时之和不作为端到端耗时。

## 实现

在现有直接读取设备内存的 INT8 GEMM 上，将输出列块 BN 从64扩到128，分别测试 WN=2/4。
使用真实前缀中的13种矩阵形状，先逐位比对输出，再筛选中位耗时降低超过5%的形状。
未选中或新的输入形状回退到原实现，文本长度不固定。实验实现位于 `experiments/prefix_tiles_20261106/`。

26项单算子候选均与原始输出逐位一致。只有 `(M,N,K)=(288,3072,128)` 的图像输入投影通过筛选，选择 WN=4：
单算子中位耗时由0.363437降到0.252000 ms，减少0.111438 ms。
这些是独立调用的墙钟计时，包含调度开销，不能当作正式推理中的逐内核 GPU 时间。

两个各出现19次的主干形状扩大分块均退化：

| M,N,K | 原始 ms | BN128/WN2 ms | BN128/WN4 ms |
|---|---:|---:|---:|
| 328,27648,3072 | 1.547355 | 1.620980 | 1.627083 |
| 328,3072,12288 | 1.166729 | 1.554251 | 1.796500 |

扩大分块可能增加寄存器压力、降低占用率；目前这是解释假设，没有逐内核占用率证据。实测已足以排除全局扩大分块。

## 结果与证据

全部26项单算子候选与6轮完整模型测试已结束。

| 阶段 | 原版 native-w1 E2E ms | 投影分块候选 E2E ms |
|---|---:|---:|
| 初筛 | 149.681640 | 145.147996 |
| ABBA 第一次 | 144.529453 | 145.086935 |
| ABBA 第二次 | 145.016045 | 147.983773 |
| ABBA 两轮均值 | **144.772749** | **146.535354** |

候选较同轮原版慢1.762605 ms（1.22%），**不合入推荐路径**。此前146.903ms与本轮144.773ms都是同一个 native-w1 版本的不同批次结果，不能称为本轮优化收益。

初筛候选前缀67.339ms，对照67.453ms；复测候选约67.424ms，对照两轮约67.487ms。局部收益过小，不能据此宣称端到端提速。

候选标准输出、51个案例及H=1/H=64/长文本三组动态输入与本轮原版逐位一致。W1标准样本相对既有高精度参考的RMSE仍为0.51806158；本次没有改善该量化误差。

下一步应优先定位反复执行的主干投影（上表两个19次形状）在量化、矩阵计算、写回之间的占比，再针对数据复用与融合调度设计实验。扩大列块已被本轮实测否定，不宜继续全局推广；当前没有逐内核时间线，不能把寄存器压力假设当成已证实瓶颈。

原始数据保存在远端 `records/prefix_tiles_20261106/`，包括标准输出、51个案例、三组动态输入与全部测量样本。

数值检查区分两个参照：候选与当前 native-w1 的一致性，以及 native-w1 相对于高精度参考的既有误差。逐位一致不代表 W1 的既有量化误差消失。
