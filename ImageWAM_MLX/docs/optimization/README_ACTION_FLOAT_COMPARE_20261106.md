# Action 浮点与量化计算对照（2026-11-06）

## 测试范围

基于当前新 MLX 运行时、speed + all_int8 前缀，仅替换 action 专家。三张 RoboTwin 图片每次重新编码，文本特征缓存命中，H16、10步、固定输入与噪声。每进程10次预热、50次正式测量，模块另测50次，51案例及H1/H64/长文本验证。端到端包含输入预处理到CPU动作，不含加载与输出落盘。

环境同 [版本索引](../../README_INFERENCE_VERSIONS.md)，Python 为 `records/background_20261106_xcode/builds/route4796/venv/bin/python`。

## 候选定义

- baseline：原生 W1 权重/BF16 激活，当前最快配置。
- bf16：从原始 action.safetensors 加载 BF16 权重，使用普通 BF16 GEMM。
- expanded_w1：加载阶段对 W1 权重执行一次 dequantize 并保存 BF16 张量；前向使用 BF16 GEMM，没有在线完整反量化。由于权重展开舍入和矩阵累加顺序变化，不保证与原生W1逐值相同。
- fp16：原始 action 权重转 FP16，主干激活和 KV 工作区使用 FP16；前缀 KV 在进入动作模块时转换一次并计入耗时。时间嵌入保留原 BF16 生成再转FP16，位置编码保留原实现与FP32旋转系数，归一化统计仍可使用FP32。因此不是全图所有运算统一FP16，也不是每层来回转换BF16/FP16。

## 结果

BF16组按 W1→BF16→展开W1→展开W1→BF16→W1 顺序，每种配置两轮。受竞争进程干扰的两次中断轮次排除，日志保留，重跑结果完整。

| 配置 | E2E均值 ms | action 10步均值 ms | 标准样本参考 RMSE |
|---|---:|---:|---:|
| native-w1 | 150.171436 | 47.665429 | 0.51806158 |
| 原始 BF16 | 179.828138 | 81.575630 | 0.00220279 |
| W1一次性展开BF16 | 179.999727 | 81.513785 | 0.52969840 |

原始BF16相对同期W1端到端增加29.656702ms（19.75%），动作增加33.910200ms（71.14%）。展开W1亦无速度收益。

展开W1相对原生W1在51案例中的最大动作差为0.06400514，动态案例最大差0.05658138；不能称逐值无损。原始BF16相对W1最大差较大是预期的量化方案差异，应结合高精度参考误差判断，不能当成精度退化。

浮点 action 张量共1,284,053,504字节，约1.196GiB。各进程MLX峰值均约14.192GiB，包含共同的初始化和加载阶段，不能据此宣称稳态内存相同。

FP16对照补充见后文；首轮编排的进程退出竞态已修复，失败记录保存在 `records/action_fp16_20261106/`，新测试使用 `records/action_fp16_retry_20261106/`。


## 解释边界

- 全浮点没有每次解包权重的成本，但权重读取量更大；H16较小，权重复用有限。实测能确认整体变慢，尚无逐内核带宽/占用率数据证明某一个因素是唯一原因。
- 模块开启同步剖析，端到端采用正常执行，因此模块差值不必严格等于端到端差值。
- 原始BF16/FP16恢复的是action权重精度，前缀仍为当前量化实现；不能把它们称为全模型原始浮点或高精度真值。
- 更好的标准样本RMSE不代表闭环任务成功率已经验证。对W1的最大差也不代表相对高精度参考的误差。
- 本轮排除整体切换BF16/FP16作为提速方案；没有断言每一个单层浮点GEMM都更慢。若后续测试按层混合，仍须独立端到端验证。

## FP16 ABBA 最终结果

4个进程全部完成：W1→FP16→FP16→W1，每轮10次预热、50次正式。

| 配置 | 两轮E2E ms | E2E均值 ms | action均值 ms | 标准样本参考RMSE |
|---|---|---:|---:|---:|
| 同组 native-w1 | 149.967518 / 145.038978 | 147.503248 | 约47.443 | 0.51806158 |
| FP16 action | 179.026664 / 179.406318 | 179.216491 | 约82.001 | 0.00224030 |

FP16端到端比同组W1增加 31.713243ms（21.50%）。模块数值由汇总表舍入值取均值。51案例相对W1最大动作差2.28518307，不能将其误判为相对高精度参考的误差。

结论：本轮10个有效完整测试进程支持保留 native-w1 作为速度路径。原始BF16和FP16均改善标准样本参考误差，但整体切换无法提速；W1展开BF16既未提速，也不逐值一致。没有修改默认入口。
