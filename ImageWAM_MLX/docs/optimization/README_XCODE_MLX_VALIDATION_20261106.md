# Xcode 就绪后的 MLX 适配与验证结果（2026-11-06）

## 测试条件

Apple M5 Pro，24 GiB 统一内存，macOS 27.2，Xcode 27.2 (27B52)，Metal Toolchain 27B47。
生产 MLX 0.32.4；两个独立实验构建均为 0.32.5.dev20261106，源码 commit 见 builds/*/build.json。
新构建启用 Metal JIT，部署目标 26.2，未定义 MLX_METAL_NO_NAX。构建参数与运行时版本同时变化，不能将整体收益归因于某个 PR。
speed + all_int8 prefix，文本缓存命中，三张图每次重新编码，动作去噪10步；10次预热、50次正式计时、独立50次模块统计。
每个完整任务保存标准输出、51个案例及H=1/H=64/长文本动态输入输出，共55份 npz。GPU同步后计时。模块独立采集，其和不等于端到端时间。
PI05驻留/单元测试导致2轮中断，均保留但不计入完成结果。远程桌面等系统负载仍存在，采用ABBA降低时间漂移影响。

## 精度与结论

- 新运行时基线相对本次旧运行时：55份输出最大绝对差0.032002568；标准样本RMSE 0.002526283。不是逐位一致。
- 原生W1保留已有speed量化误差，标准参考RMSE约0.518；原生W4标准参考RMSE约0.00755，速度接近但不是无损优化。
- 51个案例的比较对象是历史speed输出，而不是51个高精度真值。W4相对speed的大差异不能直接解释成精度退化。任务成功率未验证。
- 全部候选完成有限值及动态形状检查，不等于达成某个未定义的精度门限。
- 新运行时整体加速得到ABBA支持；原生W1同环境收益得到ABBA支持。W4是值得保留的精度/性能折中候选，速度收益尚不稳定。
- MXFP4/MXFP8/NVFP4及此次affine量化没有超过对应最佳原生路径；不切换为默认。
- 现有生产环境、默认推理配置与权重未修改；实验兼容性放行仅在worker进程内生效。
