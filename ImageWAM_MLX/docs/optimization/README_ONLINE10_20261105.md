## 精度与采纳决定

四种候选各51组真实输入，动作及归一化动作全部逐值一致。另以39/189-token文本、H1/H16/H64、改变原始图像尺寸/内容及状态的4组动态用例检查，预处理、VAE latent及最终动作均逐值一致。正式CLI400组输出逐值一致。归一化核额外覆盖256种uint8输入值。

这里的一致性相对于当前量化speed基线，不代表相对PyTorch无损，也不是RoboTwin闭环成功率验证。

默认不启用新padding。保留实验模块imagewam_mlx/asymmetric_vae.py，使用--vae-asymmetric显式开启，仅在MLX0.32.4、applegpu_g17s、fast_bf16 VAE组合有效；--no-vae-asymmetric优先关闭。QKV与归一化融合只保留在experiments/online10_20261105。历史正式ABBA运行时曾临时默认启用候选，原始source_snapshot保留该事实；最终代码已恢复默认原路径。
