# M5 Pro 三图推理真实性复核与代码整理

结论：确认是真实模型权重、真实 RoboTwin 数据、MPS GPU 上执行的离线动作推理。并非闭环机器人测试，尚未与 3090 输出做精度比较。

## 核验依据

- 整理前 77 个源码文件与首次归档哈希一致。
- 独立新进程重新加载模型，重新完成 1 次首次、6 次预热、20 次稳态、5 次模块测量。
- 实际重读并校验 17 个模型及附属文件（含新转换 AE），均与权重校验记录一致。
- 真实 forward pre-hook 观察到 Qwen 298、AE 54、视觉 147、动作 117、proprio 1 个带参数模块执行。参数和这些模块的张量输入均在 mps:0；动作模块合计执行 1170 次，对应 10 步去噪。
- 整理后全部动作与原基线逐位一致，归一化/反归一化输出的 max abs、MAE、RMSE 都为 0。
- 原 RoboTwin 方法对图像、状态和反归一化动作的逐元素核对通过。
- 新运行保存的 78 个输入输出文件哈希均复核通过。
